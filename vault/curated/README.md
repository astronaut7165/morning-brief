# curated — 승격 노트

`vault/raw/` 의 일일 브리핑은 매일 자동으로 쌓입니다. 그중 **다시 볼 가치가 있는 항목**만 이곳으로 옮겨 내 생각을 덧붙입니다.

## 승격 방법

1. `vault/raw/YYYY/MM/YYYY-MM-DD.md` 에서 마음에 드는 Top Pick 을 고릅니다.
2. [`_template.md`](_template.md) 를 복사해 `YYYY-MM-DD-짧은-제목.md` 로 저장합니다.
3. 원문 링크와 요약을 붙이고, **내 인사이트 / 다음 행동** 칸을 채웁니다.
4. 같은 주제가 반복되면 기존 노트에 날짜별로 이어 씁니다. 흐름이 보이기 시작합니다.

> 자동화는 `raw/` 에만 씁니다. `curated/` 는 사람만 고치는 공간이라 덮어쓰일 일이 없습니다.
